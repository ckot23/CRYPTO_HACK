# CRYPTO_HACK · NeonOS

Симулятор хакера на русском языке: пишешь настоящий код на Python, взламываешь
цели, ставишь майнеры, торгуешь криптой, учишься в школе Python и качаешь
апгрейды на чёрном рынке. Интерфейс — неоновая «хакерская ОС» NeonOS.

В репозитории живут **две версии одной игры** — с общим контентом
(`Assets/Resources/gamedata.json`) и одинаковой экономикой:

| Версия | Где лежит | Чем запускается |
|---|---|---|
| **Браузерная** | папка [`web/`](web/) | любой современный браузер, ставить ничего не нужно |
| **Unity** | корень репозитория (`Assets/`, `ProjectSettings/`) | Unity 6.6 (6000.6.3f1), в т.ч. 6.0–6.5 и 2022.3 LTS |

**Версия:** 1.1.0 · обе версии играют по одним правилам: обучение, генератор
контрактов, цепочка боссов, вход в систему и мягкий вид есть и в браузере,
и в Unity. Совпадение проверяется автоматически — генераторы обеих версий
сверяются поле в поле при одинаковых seed (см. «Проверка без Unity»).

## Быстрый старт: браузерная версия

```bash
# из корня репозитория
python3 -m http.server 8080 --directory web
# и открыть http://localhost:8080
```

Можно и совсем без сервера — двойным кликом по `web/index.html`: игра собрана
на обычных скриптах (без модулей и сборщиков), поэтому работает и с `file://`.

**Старт игры:** включаешь компьютер (кнопка питания → POST → заставка NeonOS),
NeonOS сама открывает браузер с приветствием, где нужно **ввести логин
оператора** — он сохраняется в профиль и виден в BIOS, панели задач и файлах.

**Что внутри:**

* **Одна обучающая миссия + бесконечные контракты.** «Первый скан» учит
  вызывать функции; как только он пройден, игра сама выдаёт первый контракт.
  Дальше цели генерируются случайно: цель, IP, ОС, брифинг, задание и решение
  собираются из **23 шаблонов** — переменные, `print`, f-строки, аргументы,
  индексы и `len`, циклы `for`/`while`, вложенные циклы, условия, `if/elif/else`,
  условие внутри цикла, списки, словари с `.items()`, накопление суммы, свои
  функции с `return`, `try/except`, комбо-эксплойт. У каждой цели — брифинг,
  теория, подсказки и готовое решение (без штрафа).
* **Четыре сюжетных босса** — именные цели, которые открываются по цепочке за
  закрытые контракты и требуют всего арсенала сразу:

  | Босс | Фокус | Нужно контрактов | Защита | Награда |
  |---|---|---|---|---|
  | ☠ ГИДРА | вложенные циклы, перебор узлов | 2 | 84% | ₿0.012 · $2 600 · 900 XP |
  | ⚔ ЧЁРНЫЙ АРХИВ | своя функция с `return`, `decrypt` | 5 | 88% | Ξ0.5 · $3 900 · 1300 XP |
  | ☣ СОВЕТ ДЕВЯТИ | словарь, `.items()`, `drain`, сумма | 9 | 92% | ɱ40 · $5 600 · 1800 XP |
  | ✦ ТИТАН | `try/except`, `while`, майнеры, `ghost` | 14 | 97% | ◎60 · $8 400 · 2600 XP |

  Когда босс созрел, в хак-терминале появляется пульсирующий блок «БОСС ЖДЁТ
  ВЫЗОВА», а в игре — уведомление. Провал ничего не отнимает: пробуй, пока
  не получится.
* **Реальный Python или симулятор.** По умолчанию работает встроенный
  симулятор терминала: он проверяет обязательные конструкции (`requiredPatterns`),
  ругается на забытые двоеточия, кавычки и отступы и печатает «хакерский» лог.
  Кнопка **РЕЖИМ** подключает настоящий CPython, скомпилированный в WebAssembly
  (Pyodide): тогда код выполняется по-настоящему, с игровыми заглушками
  `scan/connect/brute/bypass/decrypt/extract/drain/install_miner`. Нужен
  интернет к CDN; если его нет — игра молча остаётся на симуляторе.
* **4 уровня сложности контрактов** — ЛЕГКО / СРЕДНЕ / СЛОЖНО / ЭКСПЕРТ
  выбираются переключателем в хак-терминале. Чем выше сложность, тем больше
  защита цели и тем дороже награда — и монета разная (BTC → ETH → XMR → SOL),
  и уровень с «библиотекой кода» для неё нужны выше. Награда ещё и растёт
  на 9% за каждый закрытый контракт, так что фарм не упирается в потолок.
  Перед взятием контракта игра показывает превью: сколько дадут крипты,
  денег и XP.
* **Майнинг-ферма** — взломанные компьютеры приносят крипту каждую секунду,
  даже при закрытом окне.
* **Биржа DARKEX** — 4 монеты (₿ BTC, Ξ ETH, ɱ XMR, ◎ SOL), живые курсы каждые
  2.5 секунды, график, комиссия, которую снижает стелс-модуль.
* **Чёрный рынок** — 4 апгрейда по 4–5 уровней: скорость взлома, эффективность
  майнеров, библиотека кода, стелс.
* **Школа Python** — 5 уроков с теорией и мини-тестом (+XP и стипендия).
* **Файлы** — виртуальная файловая система: твои эксплойты, кошельки, логи майнеров.
* **Профиль** — твой логин, уровень, капитал, статистика (включая счётчик
  боссов) и 9 достижений, одно из которых даётся за всех четырёх боссов.
* **Сохранения** — автосейв в `localStorage` (ключи `cryptohack_save.json` и
  `cryptohack_code.json` — второй хранит код, написанный по миссиям).
  Контракты хранятся компактно («номер + сложность + seed») и при загрузке
  собираются заново тем же генератором — сейв не пухнет.
* **Мягкий вид.** Интерфейс без кислотных вспышек: приглушённая палитра (мята,
  небесный, роза, янтарь), скругления вместо прямых углов, светлая кайма и
  рассеянные тени вместо жёстких свечений, стеклянные панели с размытием,
  мягкий фон с авророй и виньеткой, плавные переходы. Пострадала только
  косметика — структура, размеры и логика экранов те же. Все элементы разом
  видно на странице `web/styleguide.html` (стиль-лист):

  ```bash
  python3 tools/web/design-preview.py 8081   # → http://localhost:8081
  ```

*Управление:* иконки слева или клавиши **1–7** — программы, **Esc** — закрыть
верхнее окно (меню, модалку), **Tab** — отступ в редакторе, **Ctrl+Enter** —
запуск кода, **F1** в меню — «как играть».

*Фон, глитч-заголовок, матричный дождь, тосты, перетаскиваемые окна и звуки —
всё синтезируется кодом: внешних ассетов, кроме двух шрифтов, в браузерной
версии нет.*

### Реальный Python в браузере

Настоящий интерпретатор поднимается в отдельном **Web Worker**, поэтому
бесконечный цикл в коде игрока не подвешивает интерфейс: по таймауту (8 секунд)
воркер убивается, а игра возвращается к симулятору. Первая загрузка Pyodide
тянет ~10 МБ с `cdn.jsdelivr.net`, дальше браузер кэширует их сам.

## Быстрый старт: Unity-версия

Подробный гайд — в [INSTALL.md](INSTALL.md).

1. **Папка проекта** — репозиторий целиком (внутри есть `Assets` и
   `ProjectSettings`). Запускать игру «изнутри» ZIP нельзя — нужна обычная
   папка на диске (архив `CRYPTO_HACK_unity_fixed.zip` в корне — та же
   Unity-версия для скачивания одним файлом).
2. **Unity Hub → Add → Add project from disk** → выбери папку репозитория → **Open**.
3. Дождись первого импорта (2–10 минут, Unity создаёт папку `Library`) и нажми
   **▶ Play**. Сцену создавать не нужно — игра стартует сама.

Дальше — как в браузерной версии: компьютер включается кнопкой питания, идёт
тест железа, NeonOS просит логин оператора, затем BIOS и рабочий стол с
семью программами. В хак-терминале слева — блок боссов, выбор сложности
(ЛЕГКО / СРЕДНЕ / СЛОЖНО / ЭКСПЕРТ с превью награды) и список целей.

```

  css/neon.css            палитра и весь интерфейс NeonOS

  js/core/                данные, модели, экономика, симулятор, звук, Pyodide
    gamedata.js           СГЕНЕРИРОВАН из Assets/Resources/gamedata.json
    generator.js          генератор случайных контрактов (23 шаблона, сложности,
                          награды, seed-детерминизм)
    bosses.js             четыре сюжетных босса: цепочка, задания, награды
  js/ui/                  окна, виджеты, редактор кода, экраны (питание, вход,

web/styleguide.html       стиль-лист: палитра, кнопки, окна, карточки, боссы
tools/web/sync-data.py    gamedata.json → web/js/core/gamedata.js
tools/web/smoke-test.mjs  автотест браузерной версии на jsdom
tools/web/dump-parity.mjs эталон контрактов для сверки с Unity-версией
tools/web/gen-unity-templates.py   generator.js + bosses.js → C# (шаблоны и боссы)
tools/web/design-preview.py  отдаёт стиль-лист на отдельном порту (проверка вида)
Assets/…                  исходники Unity-версии (C#), там же gamedata.json
  Scripts/Core/ContractGenerator.cs   генератор контрактов (порт generator.js)
  Scripts/Core/ContractTemplates.cs   СГЕНЕРИРОВАН: 23 шаблона заданий
  Scripts/Core/BossCatalog.cs         цепочка боссов
  Scripts/Core/BossCatalog.Generated.cs  СГЕНЕРИРОВАН: 4 босса
  Scripts/UI/Screens/PowerOnScreen.cs  включение компьютера (POST + заставка)
  Scripts/UI/Screens/LoginScreen.cs    «браузер» с входом в систему
Packages/, ProjectSettings/  зависимости и версия редактора Unity
tools/check_cs.py         линтер C# без Unity (tree-sitter)
tools/unity-check/        офлайн-сборка Unity-проекта и сверка с браузером
INSTALL.md                пошаговый гайд по Unity-версии
```

Разницы в правилах между версиями нет: обучение, бесконечные контракты
(23 шаблона, 4 уровня сложности), четыре сюжетных босса, логин оператора после
включения компьютера, 9 достижений и мягкая палитра — и там, и там. Контент
монет, уроков и апгрейдов общий (`Assets/Resources/gamedata.json`), а
шаблоны заданий и боссы в Unity-версии собраны тем же описанием, что в
браузерной: `tools/web/gen-unity-templates.py` переводит `web/js/core/generator.js`
и `bosses.js` в C# (`ContractTemplates.cs`, `BossCatalog.Generated.cs`) — править
их руками не нужно, правишь браузерную версию и запускаешь генератор.

Ключевая идея по коду: в браузерной версии нет ни сборщика, ни зависимостей —
обычные скрипты в общем пространстве имён `CH`, порядок подключения задан в
`index.html`. В Unity-версии, как и раньше, весь интерфейс собирается кодом
(uGUI без префабов).

## Проверка без Unity и без браузера

```bash
# 1. Контент: правим gamedata.json и раскладываем его в браузерную сборку
python3 tools/web/sync-data.py

# 2. Линтер C# (Unity-версия)
pip install tree-sitter tree-sitter-c-sharp
python3 tools/check_cs.py Assets

# 3. Unity-версия без Unity: сборка всех скриптов офлайн + сверка с браузером.
#    Сначала эталон из браузерной версии, потом проверка C#-ядра:
cd tools/web && node dump-parity.mjs > /tmp/web-contracts.json
cd ../unity-check && dotnet build            # компилируются ВСЕ Assets/Scripts
cd parity && dotnet run -- /tmp/web-contracts.json
#    Сейчас: 33 проверки, контракты и боссы совпадают поле в поле.

# 4. Автотест браузерной версии: поднимает игру в jsdom и проходит весь путь —
#    включение ПК → логин → BIOS → рабочий стол, семь программ, обучение,
#    генерация контрактов всех сложностей (56 проверок на проходимость),
#    майнер, биржа, апгрейд, сохранение, совместимость со старыми сейвами,
#    проходимость всех 23 шаблонов и всей цепочки боссов.
#    Сейчас: 85 проверок, все зелёные.
cd tools/web && npm install && npm test
```

## Лицензии

Код — учебный проект. Шрифты: DejaVu Sans Mono (Bitstream Vera / DejaVu) и
JetBrains Mono (SIL OFL 1.1) — тексты лицензий в `Assets/Resources/Fonts/` и
`web/fonts/`.
