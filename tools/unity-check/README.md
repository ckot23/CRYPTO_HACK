# tools/unity-check — Unity-версия без Unity

В песочнице нет редактора Unity, зато есть .NET SDK. Здесь лежат две проверки,
которые прогоняют **настоящие файлы** `Assets/Scripts/**` обычным `dotnet`:

| Что | Где | Зачем |
|---|---|---|
| **Сборка всего проекта** | `dotnet build` (рядом лежит `UnityCheck.csproj`) | компилирует все `.cs` игры — и ядро, и интерфейс — поверх заглушек `UnityStubs.cs`. Ловит опечатки, несуществующие методы, битые ссылки, забытые `using`. |
| **Сверка с браузером** | `parity/` (проект `Parity.csproj`) | прогоняет логику игры (генератор контрактов, боссов, экономику, сохранения) и сравнивает результат с браузерной версией поле в поле. |

`UnityStubs.cs` — маленькая подмена `UnityEngine` и `UnityEngine.UI`: только
сигнатуры (`Mathf`, `Color`, `GameObject`, `Image`, `Text`, `LayoutElement`…).
Она ничего не рисует и не нужна игре — в Unity подключаются настоящие типы.

## Запуск

```bash
# 1. Сборка всех скриптов игры (ядро + интерфейс)
cd tools/unity-check
dotnet build

# 2. Эталон контрактов из браузерной версии
cd ../web
node dump-parity.mjs > /tmp/web-contracts.json

# 3. Проверка логики Unity-ядра и сверка с эталоном
cd ../unity-check/parity
dotnet run -- /tmp/web-contracts.json
```

Если .NET ещё нет, подойдёт любой SDK 8.0+ (проекты собираются под `net10.0` —
поправь `TargetFramework` в `*.csproj`, если у тебя другая версия).

## Что проверяет сверка

* **Контент**: все 23 шаблона заданий заполнены, у каждого есть стартовый код,
  задание, подсказки, теория и решение; решение проходит собственную проверку
  конструкций (`PySim`), как в игре. Четыре босса: защиты, награды, легенды,
  решения и условия вызова.
* **Паритет с браузером** (`dump-parity.mjs` собирает эталон, C# сверяет):
  94 контракта — по всем сложностям, разным номерам контрактов, разному
  прогрессу и разным seed, плюс каждый шаблон принудительно — и 8 боссов.
  Сравниваются тексты, цели, IP, ОС, защита, концепты, брифинги, награды,
  монеты, требования и подсказки. Достаточно одного расхождения, чтобы
  проверка упала.
* **Игровой путь**: до обучения контракт не берётся; после обучения берётся
  контракт выбранной сложности; повторный взлом не удваивает счётчик; босс
  закрыт, пока не набрана цепочка; вызов босса не дублируется; вся цепочка
  из четырёх боссов закрывается и заканчивается «все боссы повержены».
* **Сохранения**: версия 2 (логин + очередь контрактов «номер + сложность +
  seed») сохраняется и восстанавливается, а старый сейв версии 1
  (8 ручных миссий) подхватывается без потери прогресса.

Вывод — построчно `✓`/`✗`, как у браузерного `smoke-test.mjs`. Сейчас зелёные
все 33 проверки.
